# Product feature reference

[Back to overview](../README.md)

| Area | Source-reviewed capability | Boundary or condition |
|---|---|---|
| Ask Locke | Conversational assistant and research entry point | Answers require legal review |
| Quick Answer | Short legal-information pass | Not equivalent to source verification |
| Source-Backed | Retrieval, source list, citation audit | Incomplete coverage and faulty interpretation remain possible |
| Deep Research | Multi-pass queries and extended synthesis | Bounded sources/excerpts; not exhaustive |
| Jurisdiction scope | 52 public U.S. jurisdictions and court registry | Coverage does not imply complete searchable law |
| Case files | Create, edit, archive, restore, delete | Authorization, confirmation and purge workflow apply |
| Documents | PDF/DOCX/text upload and analysis | Configured size/type limits |
| OCR | Durable scanned-PDF recognition and page review | Output requires human acceptance |
| Timeline | Events, dates, links and verification | Extracted dates are candidates until checked |
| Issues & Facts | Separate records with source/confidence metadata | Does not adjudicate disputed facts |
| Attorney Prep | Evidence-informed packet creation | Model-generated work product, not legal advice |
| Reports | Case reports and synthesis | Selected/bounded evidence |
| Exports | PDF/DOCX memoranda and outputs | Coverage warnings must be considered |
| History | Saved research and case material | Subject to authorization/deletion behavior |
| Usage | Actions, document/OCR pages and exports | Limits are configuration-dependent |
| Administration | Authorized admin functions | No public admin detail or access described |
| Provider routing | OpenAI or OpenRouter synthesis adapters | Other catalog names are gateway-mediated, not direct |

**Baseline:** source commit `205a11c`; actual current deployment and provider availability not independently verified.
